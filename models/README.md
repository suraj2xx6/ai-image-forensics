# Model artifacts

## Pretrained image detector

The app uses the open Nonescape Mini model for a local AI-generated versus authentic-image classification. Download the 86.7 MB Safetensors weight file into this directory:

```powershell
$modelUrl = "https://huggingface.co/e3ntity/nonescape-v0/resolve/dd9d70c10cd0f6823e2af87d553217c25fe00b3d/nonescape-mini-v0.safetensors"
Invoke-WebRequest -Uri $modelUrl -OutFile "models/nonescape-mini-v0.safetensors"
Get-FileHash -Algorithm SHA256 "models/nonescape-mini-v0.safetensors"
```

The model is distributed under Apache 2.0 by [Nonescape](https://github.com/e3ntity/nonescape). The pinned file's expected SHA-256 is `7a0d0740c813ce199bc32ed16a5f4f4915895c4c9fdee0a98bdbeedd4f3631fd`. Its output score is uncalibrated for this application and should be treated as a model result, not a validated probability or proof of origin. The model card reports its own evaluation claims; this project has not independently reproduced them.

Model files are git-ignored. Keep the downloaded file at `models/nonescape-mini-v0.safetensors`, or set `NONESCAPE_MODEL_PATH` to another local path. The app never downloads weights during startup. If Sightengine credentials are configured, uploads are sent to its hosted API; otherwise the local model analyzes them on this machine.

## Optional project-trained baseline

Place a model artifact generated by `python -m scripts.train` at `models/baseline.joblib` or configure `MODEL_PATH`.

Artifacts must contain a scikit-learn compatible `classifier`, the ordered `feature_names`, model `version`, `dataset_version`, and calibration metadata. The inference adapter validates the artifact structure and caches it by modification time. Joblib/pickle artifacts can execute code when loaded; only use a trusted training process.
